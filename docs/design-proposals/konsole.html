Material: Matt, Glas, Hybrid

Gleiche Karte, drei Oberflächen. Alle nach derselben Regel gebaut: Element in Hintergrundfarbe, Schatten als dunklerer und hellerer Ton derselben Farbe, großer Blur, kein Rand (Malewicz, neumorphism.io). Matt ist die reine Form. Glas macht Flächen und Buttons leicht durchscheinend, dahinter liegen weiche Farbflecken. Hybrid: Flächen aus Glas, Bedienelemente matt.

MattErhaben und eingelassen durch zwei Schatten. Ruhig, schwer, „aus einem Guss".

Unter der Haube probieren

In der Browser-Konsole (F12) steht ein kurzer Hinweis für Entwickler. Dazu eine humans.txt: eine Textdatei unter philipp-wendschuch.dev/humans.txt, die der HTML-Kopf per <link rel="author"> verlinkt. Darin stehen, wer die Seite gebaut hat, wann sie zuletzt aktualisiert wurde und womit sie läuft. Das ist eine alte Konvention (humanstxt.org), Entwickler tippen die Adresse gezielt ein. Webwerk hat auch eine.

Abseits vom Code
